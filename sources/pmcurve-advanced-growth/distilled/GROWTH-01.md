## Key Frameworks

### Growth Loop Structure
```
Input → Action → Output → Reinvest as Input
```

Example: User-Generated Content Loop (TripAdvisor, Kora)
1. User leaves a review/answer
2. Content gets indexed by Google
3. New user discovers via search
4. New user contributes content
5. Cycle repeats

### LinkedIn's AI-Powered Loop Acceleration
- Problem: Cognitive load of generating questions, cold start for answers
- Solution: AI generates relevant professional questions and draft bullet-point answers
- Result: Humans provide unique edited content, AI removes bottlenecks

### Growth Loop Types
1. **Viral Loops:** User invites → new users join → more invites
2. **Content Loops:** Content creation → SEO → acquisition → more content
3. **Paid Loops:** Revenue → reinvest in ads → more revenue
4. **Sales Loops:** Customer success → referrals → new customers

### Network Effect Classification
- **Direct:** Value increases as more users join (social networks)
- **Indirect:** Value increases via complementary goods (platforms)
- **Data:** More users → more data → better product → more users
