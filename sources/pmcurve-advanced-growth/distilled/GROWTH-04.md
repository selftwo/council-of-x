## Key Frameworks

### Engagement Equation
```
Engagement = Frequency × Intensity
```

**Engagement varies by product type:**
| Product Type | Engagement Metric |
|--------------|-------------------|
| Transaction | Monetary value |
| Attention | Time spent |
| Productivity | Tasks completed |

### User Segmentation (Casual/Core/Power)
**Method 1: Natural Frequency Based**
- Power users: Frequency > natural frequency
- Core users: Frequency ≈ natural frequency
- Casual users: Frequency << natural frequency

**Method 2: Business Value Based**
- Must tie to real value (LTV, CSAT delta)
- Transitions should have measurable business impact

### At-Risk User Detection
**Behavioral Signals:**
- Downward bucket transitions (power → core → casual)
- Declining engagement metrics
- Poor satisfaction scores (CSAT)
- Reduced feature usage

**Proactive Management:**
1. Identify transition patterns
2. Interview users to understand mindset shifts
3. Design interventions for each transition type

### Engagement Cohort Analysis
- Track engagement cohorts over time
- Weakening engagement = weakening PMF
- Leading indicator (vs retention as lagging indicator)

### Engagement Impact Chain
```
Higher Engagement
    ↓
Higher Acquisition (organic, referrals)
    ↓
Stronger Habits (automatic return)
    ↓
Higher Monetization (ads, upgrades, LTV)
```
